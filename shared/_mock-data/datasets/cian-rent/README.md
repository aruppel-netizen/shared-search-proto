# Долгосрочная аренда Москвы — САО

12 публичных объявлений Циан, собранных 19 октября 2026 для арендных прототипов.
Границы запроса владельца: Москва, САО, 60–150 тыс. ₽/мес., зелёная ветка.
Ближайшее метро проверено по самой карточке: Замоскворецкая линия
(`lineColor: 00701A`; в публичной выдаче Циан `lineId: 3`).
В снимке цены 65–145 тыс. ₽/мес.; Динамо, Сокол, Водный стадион,
Белорусская и Беломорская.
Комнатность не ограничивалась: студии и 1–3-комнатные объекты. Квартиры и
апартаменты различаются исходным `offer.isApartments`.

[Исходная выдача](https://www.cian.ru/cat.php?deal_type=rent&district%5B0%5D=5&engine_version=2&offer_type=flat&type=4&minprice=60000&maxprice=150000).
`collection.ndjson` содержит соответствие id → URL, цену и метро на момент сбора.
Набор продажи не изменён. Цена/география вне границ и краткосрочная аренда
отсеивались по полям каждой карточки, не только по фильтрам выдачи.

## Подключение

`Mock.use('cian-rent', {base: [335003449]})` после подключения `mock.js` и `listings.js`.
React: `getMockScenario('cian-rent', ...)` или `getListings([335003449], 'cian-rent')`.
Базовое объявление стенда — 335003449, Динамо, 120 тыс. ₽/мес.
В витрине «Мок-данные» есть фильтр «Аренда» и ссылки на `/rent/flat/<id>/`.

Цена читается из `offer.bargainTerms.price`, а не `priceTotal`. Комиссии —
`agentFee` / `clientFee` в процентах, залог — `deposit` в рублях. Ноль отличается
от отсутствующего значения. `paymentPeriod: monthly`, `leaseTermType: longTerm`.
У студий `roomsCount: null`; тип задаётся `flatType: studio`, поле не исправлялось.
`priceInfo` отсутствует: продажная цена за м² для аренды не рассчитывается.
Приватные показатели кабинета и состояния модерации задаёт сценарий прототипа.

## Сбор и проверка

Служебный Chrome с существующей сессией и открытой созданной для задачи вкладкой
аренды у Войковской. Сборщик выполняет только HTTP GET, не переключает вкладки
и не меняет аккаунт. Bootstrap разбирается как JSON без исполнения кода страницы.
В dataset попадают публичный offerData и выбранные поля выдачи; стейт зрителя,
избранное, заметки и tracking query не копируются.

```sh
RENT_COUNT=12 node _mock-data/tools/collect-rent.mjs
RAID_DATASET=cian-rent node _mock-data/tools/validate.mjs
node _mock-data/tools/validate-rent.mjs
RAID_DATASET=cian-rent node _mock-data/tools/raid.mjs model
```

По пять исходных кадров в двух размерах: fullUrl и thumbnailUrl. CDN отдаёт
WebP даже по адресу с `.jpg`; локальное расширение определяется по байтам.
Перекодирования и масштабирования нет. Имена — только id и номер кадра.
Существующие записи сохраняются при повторном запуске; старые наборы не удаляются.
